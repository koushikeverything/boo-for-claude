# Example: conflicting sources

When two sources disagree (here, the swim-meet date: Gmail says **Sunday Aug 10**, Calendar says
**Saturday Aug 9**), Boo surfaces the contradiction instead of silently choosing. The item is shown
once with `conflict_state: conflicted`, and a `conflicts` entry cites both sources. Payload:
`../../../evals/expected/05-conflicting-dates.json`.
