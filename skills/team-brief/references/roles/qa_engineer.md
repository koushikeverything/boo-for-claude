# Role pack — qa_engineer

**Top-of-mind ranking:** `tracking > incidents > code > observability > chat` (today first).

| Capability | Top of mind | FYI subgroup | Calendar |
|-----------|-------------|--------------|----------|
| tracking (Jira/Linear) | bugs assigned/reopened due today; release-blocking issues | **Updates** | release readiness |
| incidents (PagerDuty) | active incidents you're supporting | **Alerts** | — |
| code (GitHub/GitLab) | PRs needing your QA sign-off; builds ready to test | **Alerts** (builds), **Reviews** | — |
| observability (Datadog/Sentry) | new errors/regressions to reproduce | **Alerts** | — |
| chat (Slack/Teams) | someone blocked on your test result | **Updates** | — |

**Actions (drafts/preview only; approval-gated):** open source, draft a reply, update issue status
(preview→approval), preview a calendar event. Never merge/submit autonomously.

**Coverage:** productivity + tracking (mandatory) missing → blocking gap. Note recommended-but-absent
code/incidents/observability.
